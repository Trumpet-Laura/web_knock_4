# 40. APIとは何か
## APIとは
「Application Programming Interface（アプリケーション・プログラミング・インターフェース）」の略で、異なるアプリケーションやシステム同士をつなぎ、機能やデータを連携させる仕組み。
使用すると、アプリケーションに決済システムや地図システムなどを簡単に統合することができる。
Web APIでは、クライアントがサーバーにリクエストを送り、サーバーがレスポンスを返すことでデータや機能を利用する。
## REST APIとは
APIの設計スタイルの一種で、「REST（Representational State Transfer）」と呼ばれる設計の原則に沿って作られたもの。
Web上の情報を「リソース」として扱い、それぞれをURL/URIで一意に識別する。そして、リソースに対してHTTPを使って操作する。
クライアントはHTTPを使ってサーバーにリクエストを送り、操作内容をHTTPメソッドで指定する。以下代表的なメソッドである。
- GET：データの取得
- POST：データの新規作成・登録
- PUT ：データ全体の置き換え
- PATCH：データの一部更新
- DELETE：データの削除

処理結果はHTTPステータスコードという3桁の数字で表され、2xx系は成功、4xx系はクライアントエラー、5xx系はサーバーエラーを表す。
以下代表的なものである。
- 200 OK：成功
- 201 Created：リソースの作成成功
- 400 Bad Request：不正なリクエスト
- 404 Not Found：リソースが見つからない
- 500 Internal Server Error：サーバー内部のエラー

また、REST APIには「ステートレス」という特徴があり、サーバーは過去のリクエストの状態に依存せず、各リクエストを独立して処理する。
